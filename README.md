# 阿綸涅亞 NIEIA 官方網站

阿綸涅亞 NIEIA 療癒工作室的官方網站：個案療癒預約、工作坊報名、宇宙訊息抽卡與後台管理。

## 技術架構

- 主機：Cloudflare（製作期間使用免費網址，正式上線前接上 nieia.com）
- 資料庫：MongoDB Atlas（新加坡區）
- 通知：Email

## 開發階段

1. 第一階段：首頁、關於、服務、預約須知、個案預約、工作坊報名、宇宙訊息抽卡、後台預約與報名管理
2. 第二階段：療癒紀錄、回饋邀請、個案見證
3. 第三階段：會員區、線上收款、站內商店、簡體中文切換

## 專案結構

- `public/`：網站頁面、樣式與前端程式（首頁、療癒服務、宇宙訊息、工作坊、聖照選物、關於阿綸、後台、404）
- `tools/build_pages.py`：產生 `public/` 下的前台頁面
- `src/index.js`：Cloudflare Worker，負責 `/api/` 開頭的請求與 MongoDB 連線
- `wrangler.jsonc`：Cloudflare 設定

## 常用指令

- `npm install`：安裝套件
- `npm run dev`：在自己電腦上預覽網站（http://localhost:8787）
- `npm run check`：檢查能否成功打包

## 連線測試

部署後打開 `/api/health`：
- `"database": "connected"`：資料庫連線成功
- `"database": "not_configured"`：尚未在 Cloudflare 設定 `MONGODB_URI`
- `"database": "unreachable"`：連線字串、密碼或 MongoDB Network Access 有誤

## 後台

- 網址：`/admin`
- 需要在 Cloudflare 新增 Secret `ADMIN_PASSWORD`（後台密碼）
- 分頁「預約與時段」：上方查看客人預約與匯款回報，確認收款或取消（取消後時段自動重新開放）；下方新增、暫停、刪除可預約時段（時間一律為 UTC+8）
- 分頁「療癒項目」：新增、編輯、上下架、排序，前台「療癒服務」頁直接讀取
- 分頁「商品」：新增、編輯、上下架、排序、標示售完，前台「聖照選物」頁直接讀取
- 分頁「擺攤」：填寫擺攤資訊、開始／結束擺攤、暫停取號、叫號，並提供排隊頁 QR Code
- 分頁「工作坊」：場次、學員名單、點名、抽籤、大合照、結業證書與證書登記（見下方「工作坊與結業證書」）
- 第一次打開時，會自動匯入網站原本的 6 個療癒項目與 5 張聖照卡

## 預約通知信

- 新預約、客人回報匯款時，寄通知信給阿綸（透過 Resend）
- 需要在 Cloudflare 新增 Secret：`RESEND_API_KEY`、`NOTIFY_EMAIL`（填註冊 Resend 的信箱）
- 沒有設定時不會寄信，其他功能照常運作
- 還沒有自己的網域前，只能寄到註冊 Resend 的信箱；買了網域並在 Resend 驗證後，才能寄信給客人

## 擺攤模式

- 開始擺攤後，首頁最上方出現提醒，第一次進站會彈出提示
- 客人在 `/market` 取號，頁面每 15 秒自動更新，輪到時顯示「輪到你了」
- 同一支手機最多同時取 3 個號碼
- 密碼 15 分鐘內錯 5 次會暫時鎖定；更換 `ADMIN_PASSWORD` 後，所有已登入的裝置都需重新登入

## 工作坊與結業證書

後台分頁「工作坊」：

- 新增場次：名稱（中英文）、類型（身心靈／手工／其他）、實體或線上、上課日期（一天一堂，線上課可以分好幾個晚上）、總時數、一位或多位授課老師；手工課可填作品名稱
- 學員名單：一行一位「姓名, 英文姓名, Email」，可直接從試算表複製貼上；同名不會重複加入
- 點名：名單上每一堂一個勾選框；線上課的學員可在上課當天打開簽到連結（`/checkin?k=…`），輸入姓名或 Email 自行簽到
- 課前通知：每一堂有「用 Gmail 寄課前通知」，以密件副本寄給全班，信裡附上地點或線上教室與簽到連結
- 抽籤：抽人（可設定抽過不再抽）、分享順序、分組配對、抽座位或材料，可全螢幕分享
- 大合照：每場一張，上傳時自動縮小後存進資料庫；原始照片請另外備份到 Google 雲端硬碟
- 結業證書：全勤學員一鍵發證書，編號依年份流水號（WS-2026-0001），學員連結為 `/cert?c=…`（含隨機代碼，只有拿到連結的人看得到）；可用 Gmail 寄給學員
- 證書登記：可用編號、姓名、課程或老師搜尋所有發出的證書

學員的證書頁會畫出橫式證書與 IG 限時動態直式版本，可以下載或直接分享。證書頁刻意使用與網站不同的編輯設計風格（紙張底色、宋體、朱紅印章）。

已經發出證書的學員不能從名單移除，已發證書的工作坊也不能刪除，避免學員手上的連結失效。

## 注意

資料庫帳號密碼等機密資訊一律設定在 Cloudflare 的環境變數中，不放進這個 repository。
